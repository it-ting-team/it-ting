# 디굴디굴 API 명세

[서비스 명세](../spec/README.md)의 화면 항목을 처리하는 API를 영역별로 정리한다. 모든 API는 [API 공통 규칙](../api-convention.md)을 따른다. 구현한 뒤에는 Swagger(springdoc)가 만든 문서가 기준이다.

## 문서 목록

문서 번호는 서비스 명세의 번호와 같다.

| 문서 | 다루는 것 | 상태 |
|---|---|---|
| [00 공통](00-common.md) | 캠퍼스 · 층, 기수, 학기, 관심사, 자기소개 질문, 프로필 팝업과 함께 쓰는 값의 모양 | 작성함 |
| [02 로그인 · 회원가입](02-auth.md) | 이메일 가입, SSAFY 인증, 로그인, Google 로그인, 비밀번호 재설정 | 작성함 |
| 03 온보딩 | 닉네임 · 두더지, 관심사, 질문 답변, 땅굴 만들기 | 작성 전 |
| 04 내 땅굴 | 내 방, 방명록, 꾸미기, 내 정보 수정 | 작성 전 |
| 05 탐색 · 방문 | 들판, 단골, 오늘의 추천 친구, 남의 땅굴 방문, 대화 요청 | 작성 전 |
| 06 채팅 | 대화 요청 처리, 1:1 대화, 모임 대화 | 작성 전 |
| 07 모임 | 모임 찾기, 참여 신청, 모임 만들기, 내 모임, 신청 관리 | 작성 전 |

01 처음 방문은 견본 방의 내용을 프론트엔드가 갖고 있어 API가 없다. 11 운영 · 관리자는 명세에서 관리자 화면이 보류 상태라 쓰지 않는다.

## 문서를 쓰는 법

- [템플릿](_template.md)을 복사해 `docs/api/<번호>-<영역>.md`로 저장한다.
- API마다 명세의 어느 화면 · 항목을 처리하는지 적는다.
- 명세에 없는 것을 정했으면 문서 끝의 "명세에 없어 이 문서에서 정한 것"에 적는다.
